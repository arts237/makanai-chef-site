結論
  • 開封したベーコンは、冷蔵なら{% include fact.html id="bacon.fridge.period.opened" %}を目安に食べきる。
  • 使いきれない分は小分けにして冷凍。保存の目安は{% include fact.html id="bacon.freeze.period" %}。
  • スライスは凍ったまま炒め物・パスタ・スープに使える。

ベーコンは少しずつ使うことが多い食材です。開けたら、その日に使わない分をすぐ冷凍しておくと、いつでも使えます。

{% include storage-table.html food="bacon" %}

ニチレイフーズによると、開封したものは賞味期限にかかわらず早めに食べきるのが基本とされています。未開封でも、期限が短いものは最初から冷凍してよいと紹介されています。

スライス：小分けにして冷凍

  1. ラップに数枚ずつ、間を空けて並べる長いものは半分に切ってから並べます。
  2. 端から折りたたんで包み、冷凍用保存袋に入れて空気を抜く

スライス：短く切ってパラパラ冷凍

  1. 短冊切りにして、ポリ袋に入れる袋の口を広げて、キッチンバサミで直接切り入れると手軽です。
  2. 袋を振ってばらし、空気を残したまま冷凍庫へ
  3. {% include fact.html id="bacon.shake.wait" %}、ほぼ凍ったら取り出してもう一度振るそのあと冷凍用保存袋に移して空気を抜き、冷凍します。

ブロック：使う形に切ってから冷凍

ソテー用、スープ用、パスタ用など、よく作る料理に合わせて切り、1回分ずつラップで包んで冷凍用保存袋に入れます。

使うときのコツ

  • 凍ったまま：スライスやパラパラ冷凍したものは、そのままフライパンで焼いたり、炒め物・パスタ・スープに加えたりできます。ブロックも凍ったまま焼くかゆでて使えます。
  • 解凍してから：巻いて使うときなどは、冷蔵庫で自然解凍します（{% include fact.html id="bacon.thaw.fridge" %}が目安）。急ぐときは電子レンジで{% include fact.html id="bacon.thaw.microwave" %}が目安です。

一人分で使いきるコツ

  • パラパラ冷凍を1袋作っておく：ひとつかみ取り出すだけで、冷凍玉ねぎや冷凍きのこと一緒に炒めて、すぐ一品になります。
  • 開けた日のうちに分ける：「開封後は早めに」が基本なので、使う分を取ったら、残りはその日のうちに冷凍へ。
  • 袋には「食べきる日」を書く：開けた日ではなく、冷凍の目安から逆算した日付を書いておきます。
