まかないシェフの始め方

期限を覚えておくのは、シェフの仕事。レシートや注文履歴の画面をDMに送れば、読み取った食材と期限の目安が一覧で届き、選んで登録できる。期限の前日と当日の朝8時（日本時間）にDMでお知らせが届き、そのボタンから使い切るレシピへ。自分のDiscordに追加するだけで、サーバーは要らない。

無料で自分のDiscordに追加する

サーバーの管理権限は不要。追加するとDMで使い方が届く。サーバーのみんなで使いたい人はサーバーに追加する方法へ。もうサーバーで使っている人は、入れ直さなくてOK（登録もそのまま）。

  1. まかないシェフを追加する

    無料で自分のDiscordに追加する
    • 開いた画面の案内どおりに「認証」を押す
    • スマホだとブラウザで開くので、Discordへのログインや「ロボットではありません」の確認が出ることがある

    Discordには、Botをサーバーではなく「自分」に入れる方法がある。入れると、まかないシェフとのDMで、自分だけのリストとして使える。サーバーを作る必要はない。

  2. 届いたDMを開く

    追加したらDiscordアプリに戻って、DM一覧を開く。まかないシェフからお礼と使い方のDMが届いている（少し時間がかかることがある）。期限のお知らせも、このDMに届く。

    • 見当たらないときは、「メッセージリクエスト」も見てね
    • それでもなければ、下のボタンでまかないシェフのプロフィールを開いて「メッセージを送る」を押し、使い方 と送る。操作のボタンが出る
    • プロフィールが開けないときは、Discordのどこかのチャンネルや友だちとのDMで /expiry add と入力しても登録できる（返事は自分にだけ見える）
    まかないシェフのプロフィールを開く

  3. レシートか注文履歴を、DMに送る

    いちばん手軽なのは、買い物のレシートを撮るか、ネットスーパー・通販の注文履歴の画面をスクショして、まかないシェフとのDMに送ること。読み取った食材と期限の目安が一覧で届くので、いらないものを外して登録するだけ。

    • 送る前に、名前・住所・電話番号・注文番号・カード番号・店名など、読み取りに要らない部分は隠しておくと安心（注文履歴の画面には住所や名前が写りやすい）。隠さずに送った写真も、そのまま読み取りのAI（Anthropic社・米国）に送られる。まかないシェフは写真を保存しない
    • スマホはDMの入力欄の「＋」から、その場で撮っても、撮ってある写真やスクショを選んでもOK。PCは「＋」から画像を選ぶか、ドラッグして送る。レシートなら 🧾 レシートで追加 のボタンからも送れる
    • 1回に読むのは1枚目だけ。何枚かあるときは1枚ずつ送ってね。画面によってはうまく読めないこともある
    • 期限は印字を読まず、買った日（注文履歴ならお届け日、無ければ注文日）から、食材ごとのだいたいの日数で付く目安。表示の期限とはずれるので、食べる前はパッケージの表示も確認してね（日数がわからない食材は短めに付く）
    • 写真の読み取りは、無料で月5回まで。超えたら、手で登録すれば使い続けられる（翌月にまた使える）

    扱いはプライバシーポリシーのとおり。登録すると、いちばん早いお知らせの日が出る。すぐお知らせを見てみたいなら、下の「手で登録」で1つだけ期限を明日にしておくと、次の朝8時に届く。

    1つだけ試したいときは、手で登録

    DMの下にある ➕ 食材を追加 を押して食材名を入れ、期限をボタンで選ぶ。DMに文章で送っても登録できる。

    牛乳 明日 卵 10/25、豆腐 3日後

    試すなら期限を「明日」に。次の朝8時に届き、「使い切った」で外せる。「、」で区切るとまとめて登録できる。

  4. お知らせが届いたら

    • 期限の前日と当日の朝8時に、DMでお知らせが届く
    • 「使い切るレシピを提案してもらう」を押すと、期限が近い食材を使うレシピをAIが出す
    • 使い切ったら「○○ 使い切った」を押すと、確認のあとリストから外れる。次に買うとよさそうな食材も出て、そのままボタンで登録できる
    • 期限を過ぎた食材は、翌日にお知らせして、その次の日に自動で外れる。お知らせの「今すぐリストから外す」で先に外してもいい

    AIを使う提案（お知らせのボタンからのレシピ、/recipe のAI、/shopping）は、合わせて無料で1日2回まで。超えると案内だけが出て、日付が変わる（日本時間）とまた使える。

    お知らせを待たずに、何を作るか迷ったら

    冷蔵庫の中を撮ってDMに送ってもいい。読み取った食材の一覧が出るので、違うものは外し、足りないものは足して「この食材でレシピを見る」を押すと、AIがレシピを出す（登録はされない）。

    写真を送ると写真の読み取り（月5回）を1回、「この食材でレシピを見る」を押すとAIの提案（1日2回）を1回使う。AIの回数を使い切った日は、ボタンが押せなくなる。レシートなのに冷蔵庫の写真として扱われたときなどは、ボタンで切り替えられる（写真の回数もAIの回数も使わない）。

よく使う操作

ボタンでも、まかないシェフとのDMに文章で送っても、同じことができる。

写真で登録レシート・注文履歴の写真をDMに送る／🧾 レシートで追加
登録したものを見る📋 リスト を押す／リスト と送る
使い切ったお知らせのボタン／📋 リスト から選んで外す／牛乳 使い切った と送る（確認あり）
レシピを見たいお知らせのボタン／レシピ と送るとボタンが出る
次に買うもの買い足し と送る（AIなし・回数に数えない）
ボタンが見当たらない使い方 と送る

文章は決まった言い方だけを読み取る（AIは使わない）。送った文章そのものは保存もログ記録もしない。保存するのは、登録した食材名と期限だけ。写真は文章とは別で、AIで読み取る。

DMが来ないとき

  1. 📋 リスト で登録できているか見る
  2. お知らせは毎朝8時（日本時間）に、期限が今日か明日の食材について届く。8時を過ぎてから登録した場合は次の朝に届く（期限を今日にした食材は、次の朝が「期限切れ」のお知らせになる）
  3. まかないシェフをブロックしていないか、メッセージリクエストに入っていないか
  4. サーバーに追加して使っている人は、下の「サーバーに追加する方法」の手順2の設定がオンか

それでも届かないときは、サポートサーバーで教えてね。

サーバーに追加する方法（サーバーのみんなで使いたい人向け）

自分が管理しているサーバーに入れると、そのサーバーのメンバーも使える。登録とお知らせは一人ずつ別々。もうサーバーに入れて使っている人は、そのままでOK（登録もそのまま）。

サーバーに追加する
  1. 開いた画面で、入れたいサーバーを選んで「認証」を押す（Botを追加できるのは、そのサーバーの管理権限がある人だけ）。Botに渡す権限は「チャンネルを見る・メッセージを送る・埋め込みリンク」の3つだけ。追加した人には、使い方のDMが1通届く
  2. DMが届く設定か確認する: PCはサーバーのアイコンを右クリック、スマホはサーバー名をタップして「プライバシー設定」を開き、「サーバーにいるメンバーからのダイレクトメッセージを許可する」がオンか見る（表記はアップデートで変わることがある）
  3. 登録は、まかないシェフとのDM（上の手順2〜3と同じ）か、サーバーのチャンネルで /expiry add から。/expiry の返事は本人にだけ見える。/recipe に食材を入れて検索した結果は、チャンネルのほかの人にも見える

サーバーのチャンネルでは、まかないシェフは文章を読まない。文章での操作は、まかないシェフとのDMだけ。メンバーには使い方のDMは届かないので、このページを共有すると案内しやすい。

知っておいてほしいこと

  • 表示は日本語だけ
  • 期限の登録・お知らせ・内蔵レシピ検索は無料。AIを使う提案は合わせて1日2回、写真の読み取りは月5回まで無料。月額480円（税込）のプレミアムプランは、この回数が増える（上限あり）
  • コマンド（/expiry /recipe /scan /shopping）でも、同じことができる
  • 自分のアカウントに追加すると、ほかのサーバーやDMでもコマンドを打てる。ただし /recipe に食材を入れて検索した結果は、その場所のほかの人にも見えることがある。登録や一覧は、まかないシェフとのDMで使ってね
  • 期限の目安やレシート・注文履歴からの推定は、未開封・適切な保存を前提にした参考値。AIのレシピは誤りを含むことがあるので、アレルギーや加熱の具合は自分で確かめてね。食べられるかどうかは、商品の表示と食材の状態を見て判断してね。お知らせは、Discordの障害やDMの設定によって届かないことがある
  • やめたいときは、外す前に、プレミアムの人は /manage で解約し、📋 リスト から登録を外しておく（外すと操作できなくなるため）。そのあと、Discordの「設定 → 認証済みアプリ」から外す（サーバーに入れた場合は、サーバー設定の「連携サービス」から）。外したあとでも、解約やデータの削除は頼める（info@opera-ai.jp へメールで。くわしくはプライバシーポリシーの7。わからないときはサポートサーバーで聞いてね）
