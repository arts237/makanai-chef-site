まかないシェフの始め方

食材と期限を登録しておくと、期限の前日と当日の朝8時にDiscordのDMでお知らせが届くBot。DMのボタンから、期限が近い食材を使うレシピも出せる。自分用のサーバーを作れば、一人でも使える。

まかないシェフを追加する

自分のサーバーがある人は、このボタンからすぐ追加できる。ない人は下の1から。

  1. 自分用のサーバーを作る

    自分が管理しているサーバーがあれば、ここは飛ばしてOK

    • Discordの左にあるサーバー一覧の「＋」（サーバーを追加）を押す
    • 「オリジナルの作成」→「自分と友達のため」を選ぶ
    • 名前を入れて「新規作成」（名前はなんでもいい。例: 冷蔵庫）

  2. まかないシェフを追加する

    まかないシェフを追加する
    • 開いた画面の案内どおりに、さっき作ったサーバーを選んで「認証」を押す
    • スマホだとブラウザで開くので、Discordへのログインや「ロボットではありません」の確認が出ることがある
    • Botを追加できるのは、そのサーバーの管理権限がある人だけ（自分で作ったサーバーなら自分）

    Botに渡す権限は「チャンネルを見る・メッセージを送る・埋め込みリンク」の3つだけ。

  3. DMが届く設定か確認する

    • PCはサーバーのアイコンを右クリック、スマホはサーバー名をタップして「プライバシー設定」を開く
    • 「サーバーにいるメンバーからのダイレクトメッセージを許可する」がオンになっているか見る

    オフだとお知らせが届かないので、念のため確認してね。Discordの画面の表記は、アップデートで変わることがある。

  4. 食材を登録する

    サーバーのチャンネルで /expiry と打つと候補が出るので add を選ぶ。item に食材名、date に日付を半角で入れる。

    /expiry add item:牛乳 date:2026-10-15

    日付を明日にすると、翌朝DMが届いて試せる。

    レシートの写真でまとめて登録

    /scan receipt の photo 欄にレシートの写真を付けると、購入日から期限をざっくり出して、まとめて登録する（無料は月5回）。

    表示の期限とはズレるので、肉・魚は袋の表示も見てね。店名や名前が写っている部分は隠してOK。

    おまけ: すぐ試す

    DMを待たずに試すなら、/recipe と打って ingredients（食材）の欄は空のまま送信。登録した食材のうち期限が近いものを使うレシピをAIが出す（自分にだけ見える）。

    AIのレシピ・買い足しの提案は、/recipe のAI・DMのボタン・/shopping を合わせて無料で1日2回まで。1日2回を超えると案内だけが出て、日付が変わる（日本時間）とまた使える。

このあと届くもの

期限の前日と当日の朝8時にDMが届く。DMのボタンを押すとレシピが出て、使い切ったらボタンで登録から外せる。期限を過ぎた食材は、翌日にお知らせして、その次の日に自動で外れる（DMを受け取れない設定でも外れる）。DMは登録した本人にだけ届く。

DMが来ないとき

  1. /expiry list で登録できているか見る
  2. 期限の日付が今日か明日か（DMは朝8時に届く）
  3. 手順3の設定がオンになっているか
  4. Botをブロックしていないか、メッセージリクエストに入っていないか

知っておいてほしいこと

  • 表示は日本語だけ
  • 期限の登録・お知らせ・内蔵レシピ検索は無料。AIのレシピ・買い足しの提案は合わせて1日2回、写真の読み取りは月5回まで無料。月額480円（税込）のプレミアムプランは、この回数が増える（上限あり）
  • レシピや期限の目安は参考情報。食べられるかどうかは、商品の表示と食材の状態を見て判断してね
  • どんなBotか詳しく → トップページ
  • 困ったら サポートサーバー へ。利用規約・プライバシーポリシー
